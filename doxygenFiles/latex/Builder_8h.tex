\doxysubsection{Detailed Description}
Defines the \mbox{\hyperlink{classBuilder}{Builder}} interface for constructing \mbox{\hyperlink{classQuery}{Query}} objects. 

The \mbox{\hyperlink{classBuilder}{Builder}} class serves as the base for specific query builders such as \mbox{\hyperlink{classItemQueryBuilder}{Item\+Query\+Builder}} and \mbox{\hyperlink{classMiscQueryBuilder}{Misc\+Query\+Builder}}. It provides the shared structure and interface used to assemble \mbox{\hyperlink{classQuery}{Query}} objects.
