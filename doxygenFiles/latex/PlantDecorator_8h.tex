\doxysubsection{Detailed Description}
Abstract decorator for extending \mbox{\hyperlink{classPlant}{Plant}} behavior dynamically. 

This class implements the Decorator pattern, allowing plant objects to be extended with new features (e.\+g., pots, wrapping) without modifying the original \mbox{\hyperlink{classPlant}{Plant}} class.
