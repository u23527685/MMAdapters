\doxysubsection{Detailed Description}
Defines the abstract interface for plant care routines. 

The \mbox{\hyperlink{classPlantCareRoutine}{Plant\+Care\+Routine}} class provides a template for applying care operations (watering, fertilizing, and sunlight exposure) to plants. It supports dynamic creation of specific care routines.
