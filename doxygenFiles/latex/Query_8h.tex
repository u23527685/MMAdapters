\doxysubsection{Detailed Description}
Represents a query within the plant management system. 

The \mbox{\hyperlink{classQuery}{Query}} class encapsulates a specific question or request related to a plant or inventory operation. It is built using the \mbox{\hyperlink{classBuilder}{Builder}} pattern to allow flexible creation of query objects.
