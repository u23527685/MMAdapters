\doxysubsection{Detailed Description}
Abstract builder for constructing \mbox{\hyperlink{classQuery}{Query}} objects. 

Provides setters for configuring type, question, and target \mbox{\hyperlink{classPlant}{Plant}} items. Concrete subclasses customize the construction process.
