\doxysubsection{Detailed Description}
Abstract factory interface for creating \mbox{\hyperlink{classPlant}{Plant}} objects. 

The \mbox{\hyperlink{classPlantFactory}{Plant\+Factory}} defines a consistent interface for creating different types of plant objects. Concrete subclasses (e.\+g., \mbox{\hyperlink{classFlowerFactory}{Flower\+Factory}}) must implement the creation logic.
