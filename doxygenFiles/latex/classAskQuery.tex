\doxysubsection{Detailed Description}
Director class that simplifies \mbox{\hyperlink{classQuery}{Query}} object creation using builders. 

This class manages temporary \mbox{\hyperlink{classBuilder}{Builder}} instances to construct \mbox{\hyperlink{classQuery}{Query}} objects. It abstracts the builder selection and configuration process, providing simple methods for common query types.
