\doxysubsection{Detailed Description}
Defines the \mbox{\hyperlink{classTransactionSnapshot}{Transaction\+Snapshot}} class for storing details of a single order transaction. 

Each snapshot captures order details such as order number, total amount, quantity, and optional decorations applied to the purchased plant.
