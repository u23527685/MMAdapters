\doxysubsection{Detailed Description}
Abstract factory for creating staff members. 

Defines an interface for factories to produce \mbox{\hyperlink{classFloorStaff}{Floor\+Staff}} and \mbox{\hyperlink{classSalesStaff}{Sales\+Staff}}. Concrete factories implement creation methods for employees or managers.
