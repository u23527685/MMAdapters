\doxysubsection{Detailed Description}
Director for creating different types of \mbox{\hyperlink{classQuery}{Query}} objects using builders. 

This class provides a simplified interface for creating \mbox{\hyperlink{classQuery}{Query}} objects using the \mbox{\hyperlink{classBuilder}{Builder}} pattern. It handles the details of choosing and configuring the appropriate builder (\mbox{\hyperlink{classItemQueryBuilder}{Item\+Query\+Builder}} or \mbox{\hyperlink{classMiscQueryBuilder}{Misc\+Query\+Builder}}) based on the type of query needed.
