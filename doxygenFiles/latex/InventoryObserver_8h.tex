\doxysubsection{Detailed Description}
Abstract base class for observers monitoring plant inventory changes. 

\mbox{\hyperlink{classInventoryObserver}{Inventory\+Observer}} defines the interface for objects that need to be notified when changes occur in the plant inventory. Concrete observers must implement the update method to respond to inventory changes.
