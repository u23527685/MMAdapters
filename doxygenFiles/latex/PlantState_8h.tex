\doxysubsection{Detailed Description}
Defines the abstract interface for plant life cycle states. 

The \mbox{\hyperlink{classPlantState}{Plant\+State}} class represents a specific state in a plant\textquotesingle{}s life cycle (e.\+g., Growth, Distressed, Blooming). Each state defines its behavior for applying care and transitioning.
