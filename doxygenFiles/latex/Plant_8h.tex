\doxysubsection{Detailed Description}
Abstract base class representing a plant in the nursery system. 

The \mbox{\hyperlink{classPlant}{Plant}} class models a plant’s properties, lifecycle state, and care strategies. It serves as the core of the system, implementing key design patterns such as State and Observer for managing growth and life cycle notifications.
