Detailed Description

Abstract base class for water strategies. This class defines the interface for water strategies, which determine how much water to apply to a plant. Concrete strategy classes should inherit from this class and implement the applyWater and getStrategyName methods.

Abstract base class for defining water strategies.

This class defines the interface for all watering strategies, determining how much and how often a plant should be watered.
