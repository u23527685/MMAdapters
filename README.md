## 🌿 Project Description  

Welcome to *Plantopia, a gamified **Plant Nursery Simulator* inspired by the vibrant renewal of spring in South Africa.  
In Plantopia, growth isn’t just something that happens in the soil — it’s a living, dynamic system that blossoms through thoughtful design, teamwork, and creativity.

Plantopia models the intricate world of a modern nursery, where *plants, **staff, and **customers* form a thriving ecosystem.  
Each element plays a vital role:
- 🌱 *Greenhouse Management:* Nurture plants through unique care strategies and growth cycles.  
- 👩🏽‍🌾 *Staff Coordination:* Employees monitor plant health, track inventory, and assist customers through adaptive roles.  
- 🛒 *Customer Experience:* Visitors explore, customize their purchases, and interact dynamically with staff and stock availability.  

Built using *C++* and grounded in *object-oriented principles* and *design patterns*, Plantopia transforms complex, real-world nursery operations into a flexible, maintainable, and scalable simulation.  
As the nursery grows, so do your opportunities — unlock new plant types, expand your greenhouse, and cultivate deeper interactions with customers.

Every decision in Plantopia nurtures balance between nature and design — where software structure mirrors organic harmony, and where creativity, collaboration, and code come together to let innovation bloom. 🌷

## 🌾 How to Compile and Run the Program

To build, test, and analyze *Plantopia*, use the provided **Makefile** commands in your terminal:

| Command | Description |
|----------|--------------|
| `make` | Compiles all source files and builds the executable (`test`). |
| `make run` | Runs the compiled program (`./test`). |
| `make debug` | Builds the program with debugging symbols enabled (`-g`). |
| `make gdb` | Runs the program using the GNU Debugger. |
| `make valgrind` | Runs the program with Valgrind to check for memory leaks. |
| `make coverage` | Builds the program with code coverage flags. |
| `make gcov-report` | Generates a basic text coverage report using gcov. |
| `make coverage-html` | Generates an HTML coverage report using gcovr. |
| `make coverage-html-lcov` | Generates an HTML coverage report using lcov and genhtml. |
| `make clean` | Cleans up all compiled and generated files. |
| `make clean-html` | Cleans up HTML coverage reports only. |

💡 *Tip:* Run `make clean` before rebuilding to ensure a fresh compilation.
